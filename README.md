# АлкоТрекер

Веб-приложение для учёта и контроля употребления алкоголя (аналог «АлкоСтат»):
дневник, аналитика, калькулятор промилле и импорт данных из Excel.

ВКР / демонстрационный экзамен, специальность **09.02.07**
«Информационные системы и программирование».

## Стек

| Слой | Технологии |
|---|---|
| Клиент | **React 18** (Vite), чистый CSS, собственные SVG-диаграммы без библиотек |
| Сервер | **Node.js + Express**, REST API, сессии (express-session) |
| База | **MySQL** (utf8mb4), 8 таблиц + 3 представления, запросы через mysql2 |
| Безопасность | bcrypt-хэши паролей (bcryptjs), подготовленные SQL-выражения, изоляция данных по пользователям |

## Возможности

- **Регистрация и вход** — логин/пароль, пароль хранится только bcrypt-хэшем,
  сессия в httpOnly-cookie; данные каждого пользователя изолированы
- **Дневник** — записи «что/сколько/когда/где/с кем/почему», авто расчёт доз,
  оценка дня (сон, утреннее состояние, заметка)
- **Аналитика** — 17 карточек показателей, дозы по дням недели, структура по
  типам напитков, тренд, топ-5, серии трезвости, связь с качеством сна
- **Калькулятор промилле** — формула Э. Видмарка (C = A / (m × r) − β × t)
- **Отчёты** — экспорт дневника в CSV (UTF-8 c BOM, открывается в Excel)
- **Импорт из Excel** — CSV-версии исходных таблиц загружаются в базу
  CLI-скриптом, повторный запуск не создаёт дубликатов

## REST API

| Метод и путь | Назначение |
|---|---|
| POST `/api/auth/login` · `/register` · `/logout` | вход, регистрация, выход |
| GET `/api/auth/me` | текущий пользователь |
| GET `/api/types` · `/api/drinks` · `/api/places` · `/api/reasons` · `/api/companies` | справочники |
| GET/POST `/api/entries`, PUT/DELETE `/api/entries/:id` | записи дневника |
| GET `/api/entries/export` | экспорт дневника в CSV |
| GET/POST `/api/daily` | ежедневные показатели (сон, утро, заметка) |
| GET/PUT `/api/profile` | профиль (пол, вес — для формулы Видмарка) |
| GET `/api/stats?mode=summary\|by_weekday\|by_type\|trend\|top_drinks` | аналитика |

Все ответы в едином формате: `{"ok": true, "data": ...}` /
`{"ok": false, "error": "..."}`. Без сессии все запросы, кроме авторизации,
возвращают 401.

## Быстрый старт

```
1. Импортировать server/sql/alkotracker_full_dump.sql в MySQL (phpMyAdmin)
2. cd server && npm install && npm start        # API на :3000
3. cd client && npm install && npm run dev      # интерфейс на :5173
4. Открыть http://localhost:5173, вход: demo / demo123
```

Подробно — в [INSTALL.md](INSTALL.md).

## Примечание

Приложение не ставит диагнозов и не оценивает — только факты и цифры.
Расчёт промилле ориентировочный (формула Видмарка), не является
медицинским заключением.
