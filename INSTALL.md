# АлкоТрекер — установка и запуск

Веб-приложение «АлкоТрекер» (трекер алкоголя, аналог АлкоСтат):
**React + Node.js (Express) + MySQL**. Специальность 09.02.07, ВКР/ДЭ.

---

## Требования

| Программа | Версия | Зачем |
|---|---|---|
| **Node.js** | 18 или новее | сервер и сборка клиента (nodejs.org, LTS) |
| **npm** | идёт с Node.js | установка пакетов |
| **MySQL** | 5.7+ / 8.x / MariaDB 10.4+ | база данных (OpenServer или XAMPP) |

Проверка: `node -v` и `npm -v` в терминале (консоль OpenServer тоже подойдёт).

---

## Шаг 1. База данных

Запустите MySQL (в OpenServer/XAMPP — кнопка «Запуск»), затем откройте
**phpMyAdmin** (обычно http://localhost/phpmyadmin, пользователь `root`).

**Вариант А (рекомендуется) — полный дамп, всё сразу:**
1. Вкладка «Импорт» → выбрать файл `server/sql/alkotracker_full_dump.sql` → «Вперёд».
2. Готово: схема, справочники, демо-дневник (111 записей) и демо-пользователь.

**Вариант Б — схема + импорт данных из CSV (Excel):**
1. Импортируйте `server/sql/alkotracker_schema.sql` (только таблицы, без данных).
2. Выполните шаги 2–3 ниже, затем в каталоге `server` запустите:
   ```
   npm run import
   ```
   Импортёр перенесёт данные из `server/data/csv/*.csv` (пересохранённые
   таблицы Excel) в базу и создаст демо-учётную запись.

## Шаг 2. Настройка подключения

Откройте `server/config.js` и при необходимости уточните параметры:

```js
module.exports = {
    host: '127.0.0.1',
    port: 3306,
    user: 'root',
    password: '',          // пароль root в вашей сборке
    database: 'alkotracker',
};
```

## Шаг 3. Сервер (порт 3000)

```
cd server
npm install      # один раз
npm start        # запуск API
```

Должно вывести: `API АлкоТрекер запущено: http://localhost:3000`.
Если пишет «Не удалось подключиться к базе данных» — проверьте шаги 1–2.

## Шаг 4. Клиент

**Вариант А — режим разработки (Vite, порт 5173):**
```
cd client
npm install      # один раз
npm run dev
```
Откройте **http://localhost:5173** — запросы к `/api` автоматически
уходят на сервер (прокси настраивается в `client/vite.config.js`).

**Вариант Б — собранная версия (без второго терминала):**
```
cd client
npm install
npm run build    # собирает клиент в client/dist
```
Теперь достаточно одного сервера: откройте **http://localhost:3000** —
Express раздаёт собранный клиент сам (сборка уже включена в архив).

## Шаг 5. Вход

- Демо-учётная запись: логин **demo**, пароль **demo123**
- Или нажмите «Зарегистрироваться» и создайте своего пользователя —
  данные разных пользователей изолированы.

## Тесты

Из каталога `server`:

| Команда | Что проверяет |
|---|---|
| `npm test` | 44 юнит-теста бизнес-логики (формула Видмарка, дозы, валидация, bcrypt) — без базы |
| `node tests/api_tests.js` | интеграционные тесты REST API (нужны запущенные MySQL и сервер) |

## Импорт данных (этап ДЭ «перенос данных из Excel в БД»)

```
cd server
npm run import              # обычный запуск
npm run import -- --force   # очистить дневник и загрузить заново
```

Исходные таблицы Excel лежат в `server/data/` (`dnevnik.xlsx`,
`spravochniki.xlsx`), их CSV-копии — в `server/data/csv/`.
Повторный запуск не создаёт дубликаты.

## Чек-лист проверки (9 шагов)

1. `node -v` — Node.js 18+ установлен
2. phpMyAdmin открывается, база `alkotracker` импортирована
3. `cd server && npm install && npm start` — «API АлкоТрекер запущено»
4. `npm test` — «44 OK, 0 FAIL»
5. `node tests/api_tests.js` — «0 FAIL»
6. Клиент открывается (5173 в dev-режиме или 3000 с собранной версией)
7. Вход demo/demo123 работает, вкладки Дневник/Аналитика/Профиль переключаются
8. «Добавить запись» → выбор напитка подставляет крепость/объём/цену →
   запись появляется в дневнике и в аналитике
9. «Экспорт дневника в CSV» скачивает файл, который открывается в Excel
   с кириллицей без кракозябр

## Частые проблемы

| Симптом | Решение |
|---|---|
| `ECONNREFUSED 127.0.0.1:3306` | MySQL не запущен или неверный порт в `config.js` |
| `ER_ACCESS_DENIED_ERROR` | неверный логин/пароль в `config.js` (пароль root в OpenServer часто пустой) |
| `EADDRINUSE :3000` | порт занят — остановите другой процесс или запустите `PORT=3001 npm start` |
| Страница на 5173 не видит API | не запущен сервер из шага 3 |
| Кириллица в виде «????» | база создана не в utf8mb4 — импортируйте дамп заново |
