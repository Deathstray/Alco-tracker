# АлкоТрекер — установка и запуск

Веб-приложение «АлкоТрекер» (трекер алкоголя, аналог АлкоСтат):
**React + Node.js (Express) + SQLite/MySQL**. Специальность 09.02.07, ВКР/ДЭ.

Приложение поддерживает два режима базы данных:

| Режим | Что нужно установить | Когда использовать |
|---|---|---|
| **SQLite** (по умолчанию) | только Node.js | быстрый запуск, портфолио, проверяющим |
| **MySQL** | Node.js + MySQL (XAMPP/OpenServer) | защита ВКР: phpMyAdmin, полный SQL-дамп |

Код приложения в обоих режимах один и тот же — меняется только
драйвер в `server/db.js` (единый интерфейс запросов).

---

## Требования

| Программа | Версия | Зачем |
|---|---|---|
| **Node.js** | 22 или новее | сервер и сборка клиента (nodejs.org, LTS) |
| **npm** | идёт с Node.js | установка пакетов |
| **MySQL** (только для режима MySQL) | 5.7+ / 8.x / MariaDB 10.4+ | база данных (OpenServer или XAMPP) |

Проверка: `node -v` и `npm -v` в терминале.

## Вариант 1. Встроенная база SQLite (без установки чего-либо)

1. Запустите сервер:
   ```
   cd server
   npm install      # один раз
   npm start
   ```
   В Windows — двойной клик по `start.bat`.

2. При первом запуске автоматически создаётся файл `server/alkotracker.db`
   со схемой и демо-данными (демо-аккаунт demo / demo123).

3. Откройте **http://localhost:3000** — собранная версия клиента уже
   в репозитории (`client/dist`), отдельный терминал не нужен.

Чтобы начать с чистой базой — просто удалите файл `server/alkotracker.db`,
он создастся заново при следующем запуске.

## Вариант 2. Полный режим MySQL (защита ВКР)

### Шаг 1. База данных

Запустите MySQL (в OpenServer/XAMPP — кнопка «Запуск»), затем откройте
**phpMyAdmin** (обычно http://localhost/phpmyadmin, пользователь `root`).

**Вариант А (рекомендуется) — полный дамп, всё сразу:**
1. Вкладка «Импорт» → выбрать файл `server/sql/alkotracker_full_dump.sql` → «Вперёд».
2. Готово: схема, справочники, демо-дневник (111 записей) и демо-пользователь.

**Вариант Б — схема + импорт данных из CSV (Excel):**
1. Импортируйте `server/sql/alkotracker_schema.sql` (только таблицы, без данных).
2. Выполните шаги 2–3 ниже, затем в каталоге `server` запустите:
   ```
   npm run import
   ```
   Импортёр перенесёт данные из `server/data/csv/*.csv` (пересохранённые
   таблицы Excel) в базу и создаст демо-учётную запись.

### Шаг 2. Настройка подключения

Параметры MySQL лежат в `server/config.js` (блок `mysql`):
```js
mysql: {
    host: '127.0.0.1',
    port: 3306,
    user: 'root',
    password: '',          // пароль root в вашей сборке
    database: 'alkotracker',
}
```

### Шаг 3. Запуск в режиме MySQL

В Windows — двойной клик по `start-mysql.bat`, или в терминале:
```
cd server
set ALKOTRACKER_DB=mysql   # Windows (cmd); в Linux/macOS: ALKOTRACKER_DB=mysql
npm start
```
(режим также можно переключить в `server/config.js`, поле `db`)

### Шаг 4. Клиент

**Вариант А — собранная версия (без второго терминала):**
откройте **http://localhost:3000** — Express раздаёт клиент из `client/dist`.

**Вариант Б — режим разработки (Vite, порт 5173):**
```
cd client
npm install      # один раз
npm run dev
```
Откройте **http://localhost:5173** — запросы к `/api` автоматически
уходят на сервер (прокси в `client/vite.config.js`). Пересборка дистрибутива:
`npm run build`.

### Шаг 5. Вход

- Демо-учётная запись: логин **demo**, пароль **demo123**
- Или нажмите «Зарегистрироваться» и создайте своего пользователя —
  данные разных пользователей изолированы.

## Тесты

Из каталога `server`:

| Команда | Что проверяет |
|---|---|
| `npm test` | 44 юнит-теста бизнес-логики (формула Видмарка, дозы, валидация, bcrypt) — без базы |
| `node tests/api_tests.js` | интеграционные тесты REST API (нужен запущенный сервер); проходят и в SQLite, и в MySQL |

## Импорт данных (этап ДЭ «перенос данных из Excel в БД»)

```
cd server
npm run import              # обычный запуск
npm run import -- --force   # очистить дневник и загрузить заново
```

Исходные таблицы Excel лежат в `server/data/` (`dnevnik.xlsx`,
`spravochniki.xlsx`), их CSV-копии — в `server/data/csv/`.
Повторный запуск не создаёт дубликаты.

## Чек-лист проверки (9 шагов)

1. `node -v` — Node.js 22+ установлен
2. `cd server && npm install && npm start` — «API АлкоТрекер запущено»,
   база создалась сама (SQLite) или подключился MySQL
3. `npm test` — «44 OK, 0 FAIL»
4. `node tests/api_tests.js` — «50 OK, 0 FAIL»
5. Приложение открывается на http://localhost:3000
6. Вход demo/demo123 работает, вкладки Дневник/Аналитика/Профиль переключаются
7. «Добавить запись» → выбор напитка подставляет крепость/объём/цену →
   запись появляется в дневнике и в аналитике
8. «Оценить день» сохраняет сон/утро, повторное сохранение обновляет, не дублируя
9. «Экспорт дневника в CSV» скачивает файл, который открывается в Excel
   с кириллицей без кракозябр

## Частые проблемы

| Симптом | Решение |
|---|---|
| `node:sqlite is not available` | Node.js старше 22 — обновите с nodejs.org (LTS) |
| `ECONNREFUSED 127.0.0.1:3306` (режим MySQL) | MySQL не запущен или неверный порт в `config.js` |
| `ER_ACCESS_DENIED_ERROR` (режим MySQL) | неверный логин/пароль в `config.js` (пароль root в OpenServer часто пустой) |
| `EADDRINUSE :3000` | порт занят — остановите другой процесс или запустите `PORT=3001 npm start` |
| Страница на 5173 не видит API | не запущен сервер из шага 3 |
| Кириллица в виде «????» (режим MySQL) | база создана не в utf8mb4 — импортируйте дамп заново |
