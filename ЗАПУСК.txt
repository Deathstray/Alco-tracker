АЛКОТРЕКЕР — ПОЛНЫЙ АРХИВ (v2, встроенная база SQLite)
======================================================
(собран 17.11.2026 на основе твоего GitHub-репозитория)

ГЛАВНОЕ ИЗМЕНЕНИЕ
------------------
Теперь проекту НЕ НУЖНЫ ни XAMPP, ни MySQL, ни какие-либо сервисы.
Внутри — встроенная база данных SQLite: файл server\alkotracker.db
создаётся автоматически при первом запуске (с демо-данными,
аккаунт demo / demo123). Нужен только Node.js.

Это работает и для тех, кто скачает проект с GitHub:
клонировал -> npm install -> npm start -> готово.

Режим MySQL никуда не делся — для защиты ВКР: запускается через
start-mysql.bat (см. INSTALL.md). Код приложения один и тот же.

ЧТО УЖЕ СДЕЛАНО В ЭТОМ АРХИВЕ
------------------------------
1. Встроенная база SQLite (по умолчанию) + режим MySQL (опция).
2. Исправление белого экрана при добавлении первой записи.
3. Клиент собран (client\dist), зависимости сервера установлены
   (server\node_modules).
4. start.bat (SQLite) и start-mysql.bat (MySQL).
5. Все коммиты уже сделаны от твоего имени, remote настроен.

КАК ЗАПУСТИТЬ
-------------
1. Распакуй архив (например, в C:\Projects\alkotracker).
2. Двойной клик по start.bat.
3. Открой http://localhost:3000 (Ctrl+F5, если вкладка была открыта).

Вход: demo / demo123 или зарегистрируйся.

ВАЖНО ПРО ТВОИ СТАРЫЕ ЗАПИСИ
----------------------------
Записи, которые ты вносил раньше, лежат в твоей локальной базе
MySQL (XAMPP). В новом SQLite-режиме их не видно — это разные базы.
Посмотреть их: запусти MySQL в XAMPP и открой start-mysql.bat.
Дальше можешь пользоваться любым из режимов (в SQLite-базе есть
все демо-данные для аналитики).

КАК ЗАЛИТЬ НА GITHUB
--------------------
В папке проекта уже ДВА новых коммита от твоего имени:
- "fix: белый экран при добавлении первой записи (пустой дневник)"
- "feat: встроенная база SQLite — запуск без установки MySQL"

Открой папку проекта в терминале и выполни:

    git push

ЕСЛИ ЧТО-ТО НЕ ТАК
------------------
- "node:sqlite is not available" — у тебя старый Node.js, обнови
  с nodejs.org (нужен 22+, у тебя уже стоит 24 — не появится)
- Порт 3000 занят — закрой другое окно сервера и запусти заново
- Начать с чистой базой — удали server\alkotracker.db и запусти
  start.bat снова

ДЛЯ ЗАЩИТЫ ВКР (режим MySQL)
----------------------------
1. XAMPP Control Panel -> MySQL -> Start (зелёный).
2. Убедись, что база alkotracker импортирована в phpMyAdmin
   (server\sql\alkotracker_full_dump.sql) — у тебя уже сделано.
3. Двойной клик по start-mysql.bat -> http://localhost:3000.
Таблицы, представления и данные — те же, что в SQLite-версии.
