КАК ЗАПУСТИТЬ (3 ШАГА)
----------------------
ШАГ 1. Запусти MySQL:
   открой XAMPP Control Panel -> кнопка Start напротив MySQL
   (должен загореться зелёным). База alkotracker у тебя уже
   импортирована в phpMyAdmin — ничего переустанавливать не надо.

ШАГ 2. Распакуй этот архив куда удобно, например в
   C:\Projects\alkotracker
   (если распаковываешь ПОВЕРХ старой папки — сначала удали её,
   чтобы не осталось старых файлов).

ШАГ 3. Двойной клик по start.bat. Когда появится надпись
   «API АлкоТрекер запущено: http://localhost:3000» —
   открой в браузере http://localhost:3000
   (если открыта старая вкладка — обнови через Ctrl+F5).

   Вход: свой логин (записи никуда не делись, они в MySQL)
   или демо: demo / demo123.

ПОЧЕМУ У ТЕБЯ ВЫДАВАЛО ОШИБКИ (чтобы понимать)
-----------------------------------------------
- «npm error Missing script: start» в папке client —
  у клиента НЕТ скрипта start (это скрипт сервера). Клиент
  либо собирается (npm run build), либо запускается в режиме
  разработки (npm run dev). Но с собранным dist это не нужно:
  клиентом занимается сервер на порту 3000.
- «Error: Cannot find module 'express'» в папке server —
  в папке пропали установленные зависимости (node_modules):
  такое бывает, если проект пере распаковывали заново из архива
  без node_modules. Лечится командой  npm install  в папке server.
  В ЭТОМ архиве зависимости уже установлены.

КАК ЗАЛИТЬ ФИКС НА GITHUB
-------------------------
Всё уже сделано за тебя: исправление закоммичено, remote
настроен. Просто открой папку проекта в терминале и выполни:

    git push

На GitHub появится второй коммит
«fix: белый экран при добавлении первой записи».
(Пароль не спрашивает — доступ уже сохранён после первого пуша.)

ЕСЛИ ХОЧЕШЬ РЕЖИМ РАЗРАБОТКИ КЛИЕНТА (необязательно)
-----------------------------------------------------
Открой ВТОРОЕ окно терминала в папке проекта:

    cd client
    npm install      (один раз)
    npm run dev

Приложение будет на http://localhost:5173 (изменения кода видны
сразу, без пересборки). Но для защиты достаточно start.bat
и http://localhost:3000.
